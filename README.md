# GhostNetFishingFertig

Was wird benötigt?

Zum Starten werden Java 17 (JDK) und Eclipse mit Maven-Unterstützung benötigt.


Start in Eclipse

1. ZIP-Datei entpacken.

2. In Eclipse „File -> Import-> Maven -> Existing Maven Projects“ öffnen.

3. Den entpackten Projektordner auswählen, in dem die Datei pom.xml liegt, und auf „Finish“ klicken.

4. Warten, bis Eclipse alle Abhängigkeiten geladen hat. Falls anschließend noch Fehler angezeigt werden, per Rechtsklick auf das Projekt Maven-> Update Project auswählen. Für das Projekt muss JDK 17 eingestellt sein.

5. Im Ordner src/main/java das Paket de.alex.ghostnet öffnen. Dort liegt die Datei GhostNetApplication.java.

6. „Run As -> Java Application“ starten. In der Startkonfiguration muss der Projektordner als Arbeitsverzeichnis eingestellt sein.

7. Nach dem Start folgende Adresse im Browser aufrufen:

http://127.0.0.1:8080

Viel Spaß!
